# Demo | منيو مطعم السلطان جريل

منيو أونلاين لمطعم السلطان جريل: العميل يشوف المنيو، يجمع طلبه في السلة، ويبعته على واتساب المطعم. An online menu for El Sultan Grill: browse the menu, add items to the cart, and send the order to the restaurant on WhatsApp.

## المميزات | Features

- منيو مع الأسعار بالجنيه المصري. Menu with prices in Egyptian Pounds.
- سلة طلبات كاملة: زوّد، قلّل، أو احذف أي صنف. A full cart: add items, change quantities, or remove items.
- صفحة تفاصيل الطلب: الاسم والعنوان قبل الإرسال. An order details page with name and address before sending.
- الطلب بيتبعت رسالة واتساب جاهزة على رقم المطعم. The order is sent as a ready-made WhatsApp message to the restaurant.
- واجهة عربي بالكامل (RTL) بخط Cairo. Fully Arabic RTL interface with the Cairo font.
- ملف واحد `index.html` من غير أي خطوة بناء. A single `index.html` with no build step.

## التشغيل | Run

افتح `index.html` في المتصفح، أو ارفع الملفات على أي استضافة ملفات ثابتة زي GitHub Pages. Open `index.html` in a browser, or host it on any static host such as GitHub Pages.
